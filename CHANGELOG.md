# Changelog

As alterações deste pacote seguem [SemVer](https://semver.org/). A versão do schema de eventos é independente da versão do pacote.

## 0.1.0

- Fundação do SDK com contratos TypeScript, captura de interações e navegação, contexto de sessão e identidade opcional.
- Pipeline de privacidade e transporte HTTP com lotes e retentativas.

Antes de publicar uma versão, registre aqui as mudanças de API e de schema. Mudanças incompatíveis exigem a descrição `BREAKING CHANGE:` no commit correspondente e atualização dos consumidores.
